This is a high school (11th grade) project to implement python programing language in real world applications. 

A Python-based parking management system using Turtle Graphics to visually locate the nearest available parking slot, 
guide vehicles from the entry/exit, handle reservations, track parking duration, and calculate parking payments. 
MySQL integration is included for storing parking and payment information.
